# WIP reports

Canonical per-WIP research reports for this project.

## Authority

- **Roadmap (project authority):** [`../../ROADMAP.md`](../../ROADMAP.md)
- **Template for new reports:** [`WIP_TEMPLATE.md`](WIP_TEMPLATE.md)

Do not create a second roadmap here. Status changes must be reflected in `ROADMAP.md`.

## Status values

`PLANNED` · `ACTIVE` · `BLOCKED` · `REVIEW` · `CLOSED` · `CLOSED_NEGATIVE` · `SUPERSEDED`

## Closure checklist

1. RETURN filled in the WIP report  
2. Artifacts paths listed (immutable; do not overwrite prior runs)  
3. `ROADMAP.md` status updated (`REVIEW` → `CLOSED` / `CLOSED_NEGATIVE`)  
4. `GIT_COMMIT` recorded in both files  
5. `NEXT_WIP` taken from the roadmap  

## Naming

`docs/wip/<WIP-ID>.md` — WIP-ID matches the roadmap entry exactly.
